# LegacySource

This folder preserves classic GTA Control Center compatibility artifacts and migration references.

## Structure

- `VB6/` - original Visual Basic 6 source modules/forms/projects
- `Help/` - CHM/help content and historical docs
- `DAT/` - data catalogs used by the original trainer
- `Assets/` - legacy UI/audio/icon assets

Keep legacy files read-only and migrate behavior into the modern `src/GtaControlCenter.App` project.
